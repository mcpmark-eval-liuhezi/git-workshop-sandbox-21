# Exercise 2: Branching

This is exercise 2 of the Git workshop sandbox. Here we practice creating, switching between, and comparing branches.

## What to practice

1. Create a new branch with `git branch <name>` or `git switch -c <name>`.
2. List branches with `git branch`.
3. Compare branches with `git diff main..student-exercises`.
4. Clean up with `git branch -d` once you are done.

## Tip

A clean visual history makes demos much easier to follow.
