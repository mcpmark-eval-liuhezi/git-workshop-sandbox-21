# Exercise 1: Git Basics

This is exercise 1 of the Git workshop sandbox. In this file we practice basic `git add`, `git commit`, and `git branch` workflows.

## What to practice

1. Stage changes with `git add`.
2. Commit with a clear message using `git commit -m`.
3. Create and switch between branches with `git checkout -b` or `git switch`.

Have fun breaking things — this repo is disposable.
